# DepEd LRMDS

Learning Resource Management & Development System — registration module.

---

## Prerequisites

- [XAMPP](https://www.apachefriends.org/) (PHP 8.0+, Apache, MySQL)
- [Composer](https://getcomposer.org/download/) — PHP dependency manager
- [Git](https://git-scm.com/)
- A free [Mailtrap](https://mailtrap.io) account (for local email testing)

---

## First-time setup (every teammate does this once after cloning)

### 1. Clone the repo

```bash
git clone https://github.com/your-org/lrmds.git
cd lrmds
```

Place the project inside XAMPP's `htdocs` folder:
```
C:/xampp/htdocs/lrmds/   (Windows)
/Applications/XAMPP/htdocs/lrmds/   (macOS)
```

---

### 2. Install PHP dependencies

Make sure Composer is installed (`composer --version` should print a version number).

```bash
composer install
```

This reads `composer.lock` and downloads PHPMailer into `vendor/`.  
The `vendor/` folder is in `.gitignore` — never commit it.

---

### 3. Set up your environment file

```bash
cp .env.example .env
```

Open `.env` in a text editor and fill in your values:

```env
DB_HOST=localhost
DB_NAME=lrmds
DB_USER=root
DB_PASS=           # leave blank for default XAMPP

APP_BASE_URL=http://localhost/lrmds

MAIL_HOST=sandbox.smtp.mailtrap.io
MAIL_PORT=2525
MAIL_USERNAME=<your Mailtrap username>
MAIL_PASSWORD=<your Mailtrap password>
MAIL_FROM_ADDR=noreply@lrmds.deped.gov.ph
MAIL_FROM_NAME=DepEd LRMDS

VERIFY_TOKEN_TTL_HOURS=24
```

**Getting your Mailtrap credentials:**
1. Sign up free at https://mailtrap.io
2. Go to **Email Testing → Inboxes → your inbox → SMTP Settings**
3. Select **PHPMailer** from the integration dropdown
4. Copy the `Username` and `Password` shown — paste them into `.env`

> `.env` is in `.gitignore`. Never commit it. Each teammate has their own.

---

### 4. Run the database migration

1. Start XAMPP (Apache + MySQL)
2. Open **phpMyAdmin** → `http://localhost/phpmyadmin`
3. Select your `lrmds` database from the left panel
4. Click the **SQL** tab
5. Open `migrations/001_email_verifications.sql`, copy the entire contents, paste into the SQL tab, and click **Go**

You should see `email_verifications` appear in the table list on the left.

> **Status column note:** If your `users.status` column is an ENUM, also
> uncomment and run the `ALTER TABLE` at the bottom of the migration file.
> If it's a VARCHAR, skip it. Check in phpMyAdmin → your `users` table →
> Structure tab → look at the Type for the `status` column.

---

After completing the steps above your project should look like this:

## How the email verification flow works

```
User registers as Learner or Parent
          │
          ▼
register_handler.php
  • Validates input (including MX record check on email domain)
  • Inserts user with status = 'email_pending'
  • Calls send_verification_email()
      └─ Generates secure 64-char token
      └─ Stores token in email_verifications table (expires in 24h)
      └─ Sends email via PHPMailer → Mailtrap (dev) or Brevo (prod)
  • Returns { requires_verify: true }
          │
          ▼
registration_pending.php   ← "Check your inbox" page
          │
    User clicks link in email
          │
          ▼
verify.php?token=<token>
  • Valid   → sets users.status = 'active', marks token used → sign in
  • Expired → shows "link expired" with resend button
  • Invalid → shows "invalid link" with resend button
  • Already verified → shows "already active" message
          │
          ▼
resend_verification.php    ← user can request a fresh link (rate limited: 1 per 2 min)
```

## Switching to production email (Brevo)

When deploying for real, update `.env`:

```env
MAIL_HOST=smtp-relay.brevo.com
MAIL_PORT=587
MAIL_USERNAME=your-brevo-login@email.com
MAIL_PASSWORD=your-brevo-smtp-key
```

Get the SMTP key from: Brevo dashboard → **SMTP & API → SMTP → Generate a new SMTP key**

## Common errors

| Error | Fix |
|---|---|
| `Warning: .env file not found` | Run `cp .env.example .env` and fill in your values |
| `composer: command not found` | Install Composer from https://getcomposer.org/download/ |
| `Class not found: PHPMailer` | Run `composer install` in the project root |
| Email not arriving in Mailtrap | Double-check `MAIL_USERNAME` and `MAIL_PASSWORD` in `.env` |
| `SQLSTATE: Table 'lrmds.email_verifications' doesn't exist` | Run the migration SQL in phpMyAdmin |
| `SQLSTATE: Cannot add foreign key` | Your `users` table `id` column type must match — both should be `INT UNSIGNED` |
